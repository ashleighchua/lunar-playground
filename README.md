# Lunar Playground

An astrology web app that generates personalised birth chart readings, moon phase displays, and astrocartography insights.

## What it does

- Birth data form — enter date, time, and location to generate a chart
- Big Three display — sun, moon, and rising sign breakdown
- Moon phase visualisation
- Astrocartography world map — see how planetary lines overlay your geography
- Shareable chart cards
- Blog with astrology content
- Dark mode

## Stack

- Next.js + TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
